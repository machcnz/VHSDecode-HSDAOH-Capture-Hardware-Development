# Printable case for single channel AD9226 based grabbers

Dimensions (W × H × D): 96 × 67 × 68 mm

M3 screws are used with 4.6mm heat-set threaded inserts (to fit into 4.0mm diameter)

`HSDAOH_case_base.stl` - base part

`HSDAOH_case_lid.stl` - case lid
